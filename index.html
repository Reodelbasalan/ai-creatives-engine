How to install the AdFlow extension
Download AdFlow
  1. Download the AdFlow .zip using the button above.
  2. Extract (unzip) it into a folder you won't delete — for example Documents/AdFlow. If you delete the folder, the extension stops working too.
  3. Open Chrome and go to chrome://extensions
  4. In the top right, turn ON Developer mode.
  5. Click Load unpacked in the top left.
  6. Select the extracted folder — the one containing manifest.json.
  7. AdFlow will appear in the list. Pin it to your toolbar (puzzle icon → pin) for easy access.
When there's a new update, just replace the folder contents, then click Reload on chrome://extensions. No need to run Load unpacked again.
